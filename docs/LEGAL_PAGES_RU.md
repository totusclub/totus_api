# Юридические документы ООО «ТОТУСКЛАБ» в CMS

Тексты документов для сайта и приложений хранятся в `content/legal/` (HTML-тело страницы CMS) и описаны в `content/legal/pages.json`. Сайт и приложения берут их из `GET /api/pages/slug/:slug`; список и порядок — `config/cmsPages.js` (`LEGAL_CMS_PAGE_SLUGS`).

## Как обновить тексты на боевом сервере

```bash
cd /path/to/totus_API && git pull
npm run legal:check     # показывает, какие страницы изменятся, ничего не пишет
npm run legal:apply     # записывает; прежние тексты сохраняются в backups/legal-pages-<время>.json
pm2 restart api         # нужен, когда менялся config/cmsPages.js (новые адреса)
```

Повторный запуск безопасен: совпадающие тексты пропускаются. У существующих страниц меняются только название и текст — SEO, хлебные крошки и мобильный заголовок из админки сохраняются. Новые страницы создаются с полями из `pages.json`.
