## Цветовые режимы

Оба режима строго по токенам приложения (`src/theme/light.ts`, `src/theme/dark.ts`), чтобы разработка была прямой заменой токенов:

| Роль | Light | Dark |
|---|---|---|
| background (экран, шапка, таб-бар) | `#FFFFFF` (по просьбе владельца вместо `#F5F5F5`) | `#000000` |
| surface / card | `#FFFFFF` + обводка `#E0E0E0` или мягкая тень 7 % | `#1A1A1A` |
| inputBackground (поля внутри карточек) | `#FFFFFF` | `#242424` |
| backgroundSecondary / панели в карточках | `#F5F5F5` | `#2A2A2A` |
| backgroundTertiary / чипы, разделители | `#E4E4E4` | `#2A2A2A` / `#3A3A3A` |
| text / textSecondary / textTertiary / textDisabled | `#1F1F1F` / `#3D3D3D` / `#7A7A7A` / `#B8B8B8` | `#FFFFFF` / `#E0E0E0` / `#B0B0B0` / `#707070` |
| border / divider | `#E0E0E0` | `#3A3A3A` |
| tabBarActive / tabBarInactive | `#FE732E` / `#000000` | `#FE732E` / `#B0B0B0` |
| overlay (под шторками/диалогами) | `rgba(31,31,31,0.58)` | то же |
| brand / success / error / sbp | `#FE732E` / `#288556` / `#FF3E3E` / `#1D1346` | без изменений |

Фото, карта, градиент карты лояльности и цветные бейджи в Dark не меняются. В Dark-варианте экрана «Аккаунт» строка темы называется «Тёмная тема» (иконка `moon`), переключатель включён.

## Звонок в поддержку (Calling)

**Решение владельца (04.09.2026):** пользователь может звонить только в Support. Звонки другим пользователям, список контактов, «Добавить контакт» и открытие звонка из профиля другого пользователя — не нужны; отдельная вкладка Calling в таб-баре не добавляется. Таб `ChatStackScreen` в `authStack.tsx` остаётся закомментированным, `CallsScreen` с контактами в iPad-дизайн не входит.

Точка входа — «Аккаунт» → строка «Звонок в поддержку» → шторка (по коду `Account.tsx`): заголовок «Звонок в поддержку», подзаголовок «Выберите способ связи с поддержкой», кнопки «Звонок через приложение» (brand, иконка `phone`, VoIP через calling_api_v2), «Позвонить по телефону» (серая), «Отмена». В портрете шторка снизу (radius 32 сверху, handle 40×4), в ландшафте — центрированный диалог 520 pt поверх «Аккаунта»; под ней оверлей `rgba(31,31,31,0.58)`.

Активный звонок — `CallModal.tsx` без изменений логики: качество соединения, аватар-инициал «T» 156 `#FACD64`, «Поддержка Totus» / «Служба поддержки Totus Club», статус «Соединение установлено», таймер, кнопки MUTE / SPEAKER (`#F0F0F0` / dark `#2A2A2A`) и СБРОСИТЬ (`#FF3B30`). Портрет — панель на весь экран, ландшафт — панель 640 по центру. Не рисовались: баннер входящего звонка, свёрнутый звонок (MinimizedCallView), состояния «Нет ответа» / «Звонок завершён» — адаптируются тривиально.

## Принятые решения по планшетному UX

- Ширина контента = ширина экрана − 2×24; формы/карточки — в 2 колонки, списки — 2 колонки (портрет) / 3 колонки (ландшафт, Заказы и Избранное).
- Главная (по коду `home/searchSection/Search.tsx`, `planingTrip`, `PopularDestinations`): фото-фон + заголовок «Путешествия начинаются здесь», карточка поиска `#F5F5F5` r24 с сегментными табами «Тур / С перелётом» и «Отель / Без перелёта», поля «Страна, город, регион или отель», «Откуда?», «Дата вылета», «Дата возвращения», «Количество ночей», «Туристы», кнопка «Найти» (2 ряда в портрете / 1 ряд в ландшафте); ниже «Начните планирование путешествия здесь» (RecommendTripCard: фото 180, бейдж «Самый популярный», имя + ★ рейтинг + город) и «Популярные направления» (PopularDestinationCard: фото + оранжевый градиент + страна →) сеткой 3 / 4 колонки. Баннеры убраны в обеих ориентациях.
- Выдача: портрет — теги выбранных фильтров + карточки в 2 колонки; ландшафт — постоянная панель фильтров слева (иконка фильтров в шапке не нужна).
- Отель (по коду `hotel/Hotel.tsx`, секции в порядке приложения): HotelCard (фото + точки, звёзды, название, бейдж рейтинга + «N отзывов», адрес, «Показать на карте») → HotelDetailsPriceCard («от 1 396 810 ₽», «Выбрать номер») → HotelSearchSection («Дата вылета | Количество ночей», «Туристы», «Найти») → блок карты (под карточкой цены, рядом с адресом) → HotelRoomsSection («Выберите номер» + «Фильтры», DateChips «12 сен, пт / от 125 000 ₽», RoomCard: фото 200 + бейдж «AI Подбор», название, «Подробнее о номере», ✓ операторы / питание / «Быстрое подтверждение», «от 125 000 ₽ за 7 ночей с перелётом», «Все варианты») в 2 колонки (портрет) / 3 (ландшафт) → HotelDescriptionCard («Описание» + 4 раскрывающиеся строки: «Главное об отеле», «На территории», «Для детей», «Развлечения»). В ландшафте: слева фото-карточка, справа колонка «цена → поиск → адрес + карта», ниже номера и описание на всю ширину.
- Шапка Checkout — «Бронирование» (как `CheckoutHeader.tsx`); баннер «Оплатите заказ…» в коде закомментирован — не рисуется. Статусы заказов приходят из API (`status_for_client`), в макете условные.
- Детали перелёта / Оформление: в портрете цена и CTA — закреплённый низ; в ландшафте — карточка сверху правой колонки.
- Бронирование: поля туриста парами (имя/фамилия, дата рождения/пол, гражданство/документ, номер/срок), «Ваш заказ» — справа.
- Мила (Totus AI) — без изменений, на iPad просто во весь экран.

## Как рисовалось (для повторения)

Через `use_figma` (skill figma-use): мини-кит helpers (box/add/T/card/kv/btn/chip/header/screen/finish) — локально `/home/claude/ipad/kit.js` в сессии от 03.09; клонировались готовые ноды из мобильных фреймов (Hotel card `363:30595`…, статус-бар `1877:105679`, таб-бар `1882:105685`). Тексты и порядок блоков экранов — по коду totus_APP (`src/component/*`), цвета/радиусы — по `src/theme`, иконки — SVG из `src/component/UI/icons`. Dark-страница — клоны Light-фреймов с автоматическим маппингом серых цветов по токенам (`/home/claude/ipad/dark.js`); важно: при замене цветов в нодах с привязанными variables нужно создавать новый paint без `boundVariables`, иначе цвет не меняется; ноды `icon / *` из маппинга исключены — их тонировать отдельно. Правило `use_figma`: в начале каждого вызова `setCurrentPageAsync` на нужную страницу — иначе ноды создаются на «UI WEB». Скриншоты — только через `get_screenshot` с `enableBase64Response` (figma.com из контейнера 403). Постоянный фрейм `_kit` на Light-странице (x=−1500) хранит клоны статус-бара, шапки, таб-бара, плашки и иконок для новых экранов; Home/Hotel собраны скриптами `home2.js` / `hotel2.js`, Dark-клоны — `darkclone2.js` (darken + fixIcons + fixTabs).
