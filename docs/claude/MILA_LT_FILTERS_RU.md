# Мила: фильтры Level.Travel — статус

**29.09.2026.** PR https://github.com/tosmedia/totus_ai_v2/pull/2 (ветка `claude/mila-lt-filters`), ждёт слияния.

## Почему Мила «не видела» аквапарк
`search_tours` читал только первую страницу `get_grouped_hotels` без фильтров, то есть самые дешёвые отели (в Турции это Стамбул). Аквапарк искался текстом в описаниях только на этой странице.

## Что теперь
- Мила передаёт в Level.Travel те же `filter_*`, что сайдбар сайта: удобства (15 шт.), wifi, регионы, rest_type, звёзды, питание, линия, пляж, рейтинг, тип размещения, категория, мгновенное подтверждение, бюджет.
- Значения берутся из facets (`filters`) того же поиска, фильтр применяется ко всей выдаче.
- В результате инструмента есть `filters_applied`, `filters_not_available` и `hotels_matching_filters`.
- В промпте добавлено правило живого тона: без слов «фильтр», «система», «выдача».
- Проверено на реальном Level.Travel через прокси `api.totus.club/grouped-hotels`: `filter_aquapark` и `filter_regions` работают.

## Деплой
Обновить нужно только сервер Милы (`totus_ai_v2`: `npm run build`, перезапуск pm2 `totus-ai`). Приложение, сайт и API трогать не нужно.
