# QA-агент Totus — вариант Б: n8n + scheduled tasks, без стенда (RU)

**11.09.2026.** Альтернатива плану `QA_AGENT_PLAN_RU.md` (вариант А — выделенный Mac mini).
Полная версия с промптами, YAML и воркфлоу — артефакт «QA-агент Totus на n8n».

## Решения владельца
- n8n — снаружи: n8n Cloud или VPS (не на машине с устройствами)
- Устройства подключаются к **рабочему MacBook** владельца, отдельного стенда нет
- Отчёты и баги — **GitHub issues** в `tosmedia/totus_qa` + сводка в **Telegram**
- Российские сервисы в инструментах QA не используем

## Три исполнителя
| Кто | Что делает | Чего не может |
|---|---|---|
| Claude, scheduled tasks (облако) | веб-прогон встроенным браузером, чтение коммитов/PR, issues, разбор и отчёт дня | не видит USB-устройства; каждый запуск — чистая сессия |
| n8n (Cloud/VPS) | расписание, постановка задания на устройства, таймауты, Telegram, ежечасный health | не достучится до MacBook за NAT |
| MacBook | GitHub Actions **self-hosted runner** (метки `self-hosted,macOS,devices`): Maestro, WebDriverAgent, go-ios, ADB | работает только когда ноутбук включён |

Ключ схемы: ноутбук **сам забирает** задания из очереди GitHub Actions — ни облако, ни n8n внутрь него не ходят.
Локальная оболочка Claude на компьютере не подходит: изолированная Linux-VM, USB не видит.

## Сутки
- 06:30 n8n → `workflow_dispatch` qa-devices (ждёт раннера сколько нужно)
- 06:35 Claude «QA · веб»: S1–S3, S5, S6, S10, S11 + health API → `reports/<дата>/web.md`, issues `qa-bug`
- когда ноут включён: раннер → Maestro/WDA/ADB → `reports/<дата>/devices/` → push
- 09:15 Claude «QA · разбор»: дедуп, перепроверка `fixed`, issue `qa-report`
- 09:30 n8n → Telegram (5 строк + скриншоты); 18:00 — напоминание, если железа не было; ежечасно — сторож 6 URL

## Воркфлоу n8n
W1 утренний диспетчер · W2 приёмка результатов (webhook `workflow_run: completed`) · W3 сводка в Telegram · W4 ежечасный сторож прода · W5 (опц.) команды из Telegram (`/release`, `/devices`).
В n8n хранятся только GitHub PAT (scope: totus_qa) и токен бота; QA-пароли — в Keychain MacBook и GitHub Secrets.

## Замены российских сервисов
Selectel → BrowserStack/LambdaTest/Sauce Labs (опц.) · Yandex Postbox (QA-ящик) → Mailosaur/MailSlurp/IMAP ·
Slack → Telegram · хранение → репо + Actions artifacts, тяжёлое в Cloudflare R2 / Backblaze B2.
Продуктовые сервисы платформы не меняются — их тестируем.

## Ограничения
Прогон на устройствах не ежедневный; ночных и выходных прогонов нет (частично закрывает сторож n8n);
телефоны мешают работе за ноутбуком; расписание в двух местах (хозяин — n8n);
правила прода без staging те же (§8 плана А); сети РФ — только с реальной SIM.

## Деньги (ориентир, сентябрь 2026)

## Этапы
1. Облачный слой (репо, 2 задачи Claude, бот, W3+W4) — 3–5 дней, без железа
2. Раннер + Android (Maestro, W1+W2) — 3–5 дней
3. iOS, пуши, чат поддержки — ~неделя
4. Звонки S9 + еженедельная ферма
5. При желании — переезд на Mac mini = вариант А без переписывания

## Что нужно от владельца
Репо `totus_qa` + метки · fine-grained PAT только на него · Telegram-бот (токен, chat_id) ·
n8n (Cloud или VPS) · список реальных устройств · 3–5 QA-учёток и QA-ящик не на РФ-сервисе ·
доступ к TestFlight и Android-сборке · решение по админке прода (реальные данные или нет).
