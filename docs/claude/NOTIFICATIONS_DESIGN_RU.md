## Концепция

- **Точка входа:** «Аккаунт» → строка **«Уведомления»** («Заказы, оплата, напоминания и акции») с бейджем непрочитанных над «Чатом с поддержкой»; desktop — бейдж на пункте «Аккаунт» в рейле; сайт — колокольчик с бейджем в шапке, по клику поповер с последними тремя и ссылкой «Все уведомления».
- **Экран «Уведомления»:** фильтры-чипы по типам (Все / Заказы и оплата / Документы / Напоминания / Поддержка / Акции), «Прочитать все», шестерёнка → настройки; группы «Сегодня / Вчера / Ранее»; элемент — иконка типа в цветном круге (заказы `#FE732E`, оплата `#288556`, документы и поддержка `#2BA9E2`, напоминания `#5856D6`, акции `#FF9500`, система серый), заголовок, текст до 2 строк, время, у непрочитанных подложка `#FFF1EA` (Dark — brand 14 %) и точка. Тап → заказ / документы / чат / подборка (по `data.route`). Пустое состояние — «Уведомлений пока нет» + карточка «Push-уведомления выключены → Включить».
- **Настройки уведомлений:** карточка статуса разрешения на устройстве, переключатели: Заказы и оплата, Документы и статусы тура (обе всегда включены — не отключаются), Напоминания о поездке, Сообщения поддержки, Акции и предложения (по умолчанию выкл, opt-in); пояснение про тихие часы 21:00–09:00 МСК; каналы: push на этом устройстве, e-mail (desktop — уведомления в приложении, звук, список устройств; сайт — статус разрешения браузера и «Отключить»).
- **Предзапрос разрешения:** iPhone — шторка, desktop — диалог 480: «Включить уведомления?», список того, что придёт, «Включить» / «Не сейчас»; показывается после входа или первого заказа, не при запуске.
- **Push preview:** экран блокировки с тремя баннерами (оплата прошла, вылет завтра, сообщение поддержки) — правило текстов: заголовок ≤ 40 символов, текст ≤ 120, без ПД (только номер заказа и маршрут).
- **Totus_admin → «Уведомления»** (пункт после «Обращений»): вкладки **Рассылки** (форма: заголовок, текст, тип, куда ведёт, аудитория-сегменты с подсчётом получателей и устройств, отправить сейчас / по расписанию, «учитывать тихие часы», «Тестовый пуш себе», черновик; справа предпросмотр баннера и последние рассылки со статусом и открываемостью), **Напоминания** (список правил с включением и статистикой; редактор: название, событие — вылет / заезд / окончание поездки / создание заказа, смещение N дней/часов до/после, время отправки МСК, поведение в тихие часы, тип, заголовок, текст с переменными `{имя} {номер} {город} {отель} {дата_вылета} {время_вылета} {аэропорт}`, каналы Push / В приложении / E-mail, аудитория, «Тест себе», удалить), **История** (поиск, фильтры тип/канал/статус/период, сводка отправлено/доставлено/открыто/ошибки токенов, таблица со статусом и источником — Система / Рассылка №… / Напоминание «…»), вкладка **Настройки** не рисовалась.
- Dark — по токенам `dark.ts` (фон `#000`, карточки `#1A1A1A`, поля `#242424`, границы `#3A3A3A`; активные подложки — brand 16 %).

## Как рисовалось
