- Остальное — как раньше. Пустые страны из снимка не отдаются, снимок живёт 26 ч, хранится на диске `var/search-cache`.

### Яндекс ID в приложении: «Не получилось войти» после первого входа, хотя вход прошёл — [totus_APP #50](https://github.com/tosmedia/totus_APP/pull/50)

### Регистрация в приложении «Signup failed» — [totus_API #26](https://github.com/tosmedia/totus_API/pull/26) (слит)

- **Проверено:** на поддельной БД — запрос как из приложения → 201; повтор email → 400; запрос как с сайта → 201; сбой письма → 502 и повтор → 201; без имени → 400.
