# Desktop-версия Totus Club (Electron, Windows + macOS) — дизайн в Figma

**Статус:** 06.09.2026 — черновик всех экранов в Light и Dark нарисован, ждёт замечаний владельца. **Код не пишется** до утверждения дизайна (решение владельца).

## Исходные решения владельца

- Основа функционала — мобильное приложение totus_APP (те же экраны и логика), не сайт.
- Навигация — постоянный **левый сайдбар**.
- Базовый макет **1440×900**, Light и Dark; узкое (1024×768) и широкое (1920×1080) окна пока не рисуются.
- Рисуем в том же Figma-файле `u6A5og35jw0BBJyOkKl8Ij`, страницы **«DESKTOP UI · Light»** (`2024:106420`) и **«DESKTOP UI · Dark»** (`2024:106421`).

Ссылки: Light — https://www.figma.com/design/u6A5og35jw0BBJyOkKl8Ij/?node-id=2024-106420 · Dark — https://www.figma.com/design/u6A5og35jw0BBJyOkKl8Ij/?node-id=2024-106421

## Каркас окна

- Окно 1440×900, радиус 12 (macOS), тень. **Title bar 38 pt**: на macOS — «светофор» слева; на Windows — без скруглений, кнопки «свернуть / развернуть / закрыть» справа (отдельный фрейм `Desktop / Home (Windows)`). В Electron: `titleBarStyle: 'hiddenInset'` на macOS, стандартный frame или custom title bar той же высоты на Windows.
- **Сайдбар-рейл 88 pt** (по просьбе владельца 06.09 вместо 240 — только иконки с подписями под ними, граница справа `#E0E0E0`): знак-птица брендового цвета, пункты «Поиск», «Заказы», «Totus AI», «Избранное», «Аккаунт» (иконка 24 + подпись 11; активный — брендовый цвет на подложке `#FFF1EA` / в Dark brand 16 %), внизу переключатель темы (sun «Светлая» / moon «Тёмная») и аватар пользователя с именем («?» / «Гость» для гостя).
- **Контент 1352 pt**: заголовок страницы (кнопка «назад» 40×40 на `#F5F5F5`, title 24/600, подзаголовок 14) с полями 40; тело с полями 40 → рабочая ширина 1272. Фреймы длиннее 900 — на всю длину скролла, оранжевый пунктир + плашка «граница окна 1440×900».

## Экраны (18 фреймов на странице, одноимённые в Light и Dark)

| Ряд (y) | Фреймы (x = 0 / 1600 / 3200 / 4800 …) |
|---|---|
| 0 | Home, List / Tours, Hotel page, Tickets |
| 2700 | Ticket details, Booking, Checkout, Orders |
| 5400 | Order details, Favorites, Account, Login |
| 8100 | Onboarding, Totus AI, Support call, Call (active), Pending payment (x=6400), Home (Windows) (x=8000) |

- **Home**: фото-hero r24 с заголовком 32 «Путешествия начинаются здесь», карточка поиска с табами «Тур / Отель» и всеми полями в один ряд + «Найти»; «Начните планирование…» и «Популярные направления» сеткой 4 колонки. Баннеров нет.
- **List / Tours**: панель фильтров 280 слева (цена, звёзды, питание, линия пляжа, удобства, «Показать N отелей»), справа теги выбранных фильтров, сортировка, карточки в 2 колонки.
- **Hotel page**: слева фото-карточка, справа «цена → поиск → адрес и карта»; номера в 3 колонки; «Описание».
- **Tickets / Ticket details / Booking / Checkout / Orders / Order details / Favorites / Account / Login** — структура iPad-ландшафта (см. `claude/IPAD_DESIGN_RU.md`), перенесена в контент-колонку: те же секции и тексты приложения, 2–3 колонки.
- **Onboarding**: без сайдбара, панель с логотипом слева, текст слайда и «Далее» справа.
- **Totus AI**: Мила без изменений логики — чат 800 по центру, сообщения ассистента с аватаром слева / пользователя справа, карточки отелей внутри ответа с «Выбрать номер», внизу поле ввода + голос + отправка.
- **Support call / Call (active)**: диалог 520 и панель звонка 640 по центру окна поверх оверлея `rgba(31,31,31,0.58)`; звонки только в поддержку (вход из «Аккаунта»).
- **Pending payment**: диалог 480 по центру («Ожидание оплаты», таймер, «Открыть оплату снова» / «Закрыть»); остальные статусы оплаты — тот же диалог с другим текстом.

Под каждым фреймом — заметка с описанием. Цвета — токены приложения (`src/theme/light.ts` / `dark.ts`, таблица в `claude/IPAD_DESIGN_RU.md`); Dark: фон/сайдбар/шапка `#000`, карточки `#1A1A1A`, поля `#242424`, границы `#3A3A3A`.

## Что не нарисовано (адаптируется тривиально или ждёт решения)

Узкое окно 1024×768 (сайдбар сворачивается в иконки 72 pt) и 1920×1080 (контент ограничен 1120–1280 по центру); Verification (4 ячейки кода) и Signup; серые чипы-подсказки над выдачей; свёрнутый звонок (плашка в углу окна); модалки фильтров/сортировки/номера; системные меню Electron (File / Edit / View), автообновление, трей — обсудить отдельно.

## Как рисовалось (для повторения)

`use_figma` (skill figma-use); кит `/home/claude/desk/dkit_base.js` (dscreen / pageHead / body / dfinish / note; иконки — клоны из `_kit` на странице iPAD UI · Light); экраны, кроме Home и Totus AI, собраны клонированием `Content` iPad-ландшафтных фреймов (`clone_util.js`), Dark — `dark_desk.js` (маппинг серых по токенам + postD для сайдбара/шапки/переключателя темы). Каждый вызов начинать с `setCurrentPageAsync`.
