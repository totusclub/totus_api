## Концепция (одинаково на всех платформах)

- **Точка входа:** «Аккаунт» → новая строка **«Чат с поддержкой»** («Напишите нам — ответим в чате») над «Звонок в поддержку»; иконка чата на подложке `#2BA9E2` 12 % (Dark 20 %). На сайте — новый пункт меню личного кабинета с бейджем непрочитанных.
- **Экран чата:** шапка — «назад», аватар поддержки (брендовый круг `#FE732E` с белой птицей, зелёная точка «онлайн»), «Поддержка Totus» + статус «Онлайн · отвечаем в течение 5 минут» (`#288556`), кнопка «Позвонить» (открывает существующую шторку звонка в поддержку / VoIP). Таб-бар на iPhone/iPad скрыт (стековый экран, как детальные).
- **Сообщения:** поддержка — слева, пузырь `#F5F5F5` (Dark `#2A2A2A`) r16 (нижний левый 4), подпись «Анна · Поддержка Totus», время 11; пользователь — справа, пузырь `#FE732E`, белый текст, время + двойная галочка прочтения. Разделители дат («Вчера», «Сегодня»). Внутри сообщения может быть **карточка заказа** («Заказ № … · Египет, 7 ночей», отель, даты → детали заказа). Индикатор «оператор печатает» (три точки).
- **Композер:** скрепка (вложение: фото/документ), поле «Напишите сообщение…» (`#F5F5F5`, Dark `#242424`), круглая брендовая кнопка отправки; над полем — чипы быстрых тем («Вопрос по заказу», «Изменить бронирование», «Проблема с оплатой», «Документы по туру»).
- **Пустое состояние** (первое открытие): аватар, «Напишите нам», «Служба поддержки Totus Club отвечает ежедневно с 9:00 до 21:00 (МСК). Среднее время ответа — 5 минут.», чипы тем.
- **Размеры:** iPhone — пузырь ≤ 290; iPad — колонка 786 (портрет) / 800 (ландшафт), пузырь ≤ 520; Desktop — колонка 800 по центру (как Totus AI), заголовок страницы 24 + аватар 48 + «Позвонить»; Web — карточка чата r24 справа от меню ЛК 300, шапка и футер из `Home Ref`; Web mobile — полноэкранный чат, футер скрыт (как в коде).
- **Dark** — токены `src/theme/dark.ts` (фон `#000`, карточки `#1A1A1A`, поля `#242424`, границы `#3A3A3A`); в «Аккаунте» строка «Тёмная тема» с иконкой moon и включённым переключателем.
